# Финальный проект 4 спринта: Тестирование BooksCollector

# В проекте Тесты написаны на языке python 

# Список реализованных тестов:

1. `test_add_new_book_add_two_books`: Проверка добавления двух разных книг в пустую коллекцию. Проверяется, что длина словаря всех книг становится равной 2.
2. `test_add_ntw_book_valid_name`(параметризация): Проверка добавления книг с названиями разной допустимой длины (1 символ, 40 символов и среднее значение). Проверяется наличие книги в коллекции.
3. `test_add_new_book_has_no_genre`: Проверка того, что при добавлении новой книги через `add_new_book`, её жанр по умолчанию является пустой строкой.
4. `test_set_book_genre_valid`: Проверка успешной установки жанра книге из списка разрешенных жанров.
5. `test_get_books_for_children_excludes_horror`: Проверка фильтрации книг. Книга с жанром "Ужасы" не должна попадать в список книг для детей.
6. `test_add_book_in_favorites_added`: Проверка успешного добавления существующей в коллекции книги в список "Избранное".
7. `test_delete_book_favorites_deleted`: Проверка успешного удаления книги из списка "Избранное".
8. `test_add_book_in_favorites_double_not_added`: Проверка того, что одну и ту же книгу нельзя добавить в список "Избранное" дважды.

# Как запустить тесты:

Для запуска тестов необходимо установить `pytest` и выполнить команду в терминале:

  py -m pytest -v tests.py
